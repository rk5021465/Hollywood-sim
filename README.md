# Hollywood Studio Simulator — Android app

A WebView wrapper around the game (`app/src/main/assets/index.html`). Works offline; saves on the device.

## Get the APK without installing anything
1. Create a free GitHub account and a new repository.
2. Upload every file in this folder (keep the folder structure, including `.github`).
3. Open the repo's **Actions** tab → **Build APK**. It runs automatically (~4 minutes).
4. Open the finished run → download **HollywoodSim-apk** → unzip → `app-debug.apk`.
5. On your Android phone, open the APK and allow "Install unknown apps" when asked.

## Or with Android Studio
Open this folder → let Gradle sync → **Build ▸ Build APK(s)**.

# Nexa System — story game

`nexa-system/index.html` is a separate, standalone story game (open it in any browser; it saves automatically).
Peter Parker, planet Nexa, a Solo Leveling–style System: daily and situational quests, Basic and Special cards,
stats, turn-based fights, mini-games and scene art drawn live for every part of the story. Arc 1 runs from the
Prologue to the night before the school Power Competition.
