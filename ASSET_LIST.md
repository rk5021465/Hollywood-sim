# NEXA — Artwork & Audio Checklist

Drop files into these exact paths (PNG, WEBP or JPG). File name = ID. Anything missing uses the built-in fallback art, so you can add images gradually.

Recommended sizes: portraits 768×1024 (transparent PNG, character standing, waist-up or full), backgrounds 1080×1920 portrait, cards 600×860, pets 512×512.

Tip for Meta AI consistency: reuse the same description of each character in every prompt (hair, eyes, outfit, age) and only change the expression.
